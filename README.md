# Márcio — Projeto Lobo

Jogo 3D de ação brutal no navegador: Márcio invade um prédio tomado por criminosos, sobe 3 andares, derrota 3 bosses e,
quando a raiva enche, vira o **Lobisomem Márcio**. Desktop (teclado/mouse/gamepad) e celular na horizontal.

**Estado:** arquitetura e documentação prontas; construção ainda não começou (ver `docs/PROJECT_STATE.md`).
